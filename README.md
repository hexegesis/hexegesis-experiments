# Expériences Hexegesis

Ce dépôt rassemble les exemples reproductibles qui accompagnent les différents articles consacrés à Hexegesis. Chaque sous-répertoire contient un projet autonome avec ses sources, ses outils de construction et ses instructions d'exécution.
